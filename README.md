# Vision Riders Foundation website

Professional static website for Vision Riders Foundation, founded in 2018 and registered in The Gambia.

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload all five files in this folder to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main**, choose **/(root)**, then click **Save**.
6. Wait a few minutes and open the GitHub Pages address shown by GitHub.

The logo and page illustrations are embedded in index.html, so no assets folder is required.

## Other hosting companies

Upload the same files to the public website directory, commonly named public_html, htdocs or www.
